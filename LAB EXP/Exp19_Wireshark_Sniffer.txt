Experiment 19: Wireshark Sniffer for Network Traffic Analysis
=============================================

Procedure followed:
1. Opened Wireshark on Kali Linux.
2. Selected the active network interface (eth0).
3. Started packet capture.
4. Generated traffic by browsing to http://example.com and pinging 8.8.8.8.
5. Stopped the capture and analyzed packets.

Sample Captured Packets (summary view):

No.   Time       Source           Destination      Protocol  Length  Info
1     0.000000   192.168.1.25     8.8.8.8          ICMP      98      Echo (ping) request
2     0.018500   8.8.8.8          192.168.1.25     ICMP      98      Echo (ping) reply
3     1.203411   192.168.1.25     93.184.216.34    TCP       66      52211 -> 80 [SYN]
4     1.221003   93.184.216.34    192.168.1.25     TCP       66      80 -> 52211 [SYN, ACK]
5     1.221500   192.168.1.25     93.184.216.34    TCP       54      52211 -> 80 [ACK]
6     1.222800   192.168.1.25     93.184.216.34    HTTP      421     GET / HTTP/1.1
7     1.245600   93.184.216.34    192.168.1.25     HTTP      512     HTTP/1.1 200 OK (text/html)

Observation:
The capture shows the ICMP echo request/reply for the ping command and the
TCP three-way handshake (SYN, SYN-ACK, ACK) followed by an HTTP GET request
and 200 OK response for the web browsing traffic.

Result:
Successfully captured and analyzed network traffic.
