EX - 8
Execute and display the results for the following Nmap service version
and OS detection commands in Kali Linux operating systems:
i) detect the version of services running  ii) Aggressive scan
iii) Detect operating system of the target
=============================================================

Note: scanme.nmap.org is Nmap's official public test target, provided by
the Nmap project specifically for learners to practice scans legally.
